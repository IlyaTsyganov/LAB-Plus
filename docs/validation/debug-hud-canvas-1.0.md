# Debug HUD canvas validation on 1.0

The public meathook `m_add_persistent_text` wrapper calls the engine's `idDebugHUD::AddPersistentText`. It does not expose a clipping rectangle or a way to resize the persistent-text canvas. See the upstream `m34thook/gameapi.cpp` and `mh_native_api.cpp` in [brongo/m3337ho0o0ok](https://github.com/brongo/m3337ho0o0ok/tree/master/m34thook).

The user's original game 1.0 executable contains the `idDebugHUDLocal` vtable at RVA `0x25b4f48`; its Render method is at RVA `0x447920`. The persistent-text branch at RVA `0x447c78` contains `cmp eax, 0x1e0`, followed by `jg` to skip drawing. Here `eax` is the text row's Y coordinate read immediately beforehand. Thus persistent rows below Y=480 are omitted even though the earlier transient-text loop in the same method queries the GUI virtual height instead.

This is a read-only inspection of the executable. LAB Plus does not patch that method. Its Debug HUD stack now exports immutable complete row snapshots for the Vulkan presentation path, which lays them out against the full viewport. Once that path takes over, the stack removes its old engine-persistent rows to avoid duplicate rendering. The engine fallback retains one common font size and line spacing for all blocks.

The new visibility resolver was also checked against the user's running game 1.0 using read-only process memory. The actual public API's ExecuteCommandText thunk matched the validated bytes `48 89 ca 48 8b 05 <rel32> 48 8b 08 48 8b 01 48 8b 40 40 48 ff e0`. Its command-system slot and immediately preceding cvar-system slot resolved to real game objects; the latter had the exact MSVC RTTI name `.?AVidCVarSystemLocal@@`, with its Find method inside the executable at RVA `0x413650`. No remote function was invoked and no cvar or other game state was changed by that inspection. This establishes the current 1.0 resolver chain; it is not live acceptance of every other supported profile.

`DebugHudStackTests` covers 80-row snapshots, immutable generations, concurrent render-thread reads, visibility changes, engine-to-Vulkan handover and fallback restoration. The inspector keeps all ten labelled rows without a selected volume; support-plane rows remain present without a ground contact. The encounter formatter no longer drops managers after the fifth or truncates labels at 88 characters. The native invisible-numbers formatter's separate row caps and the viewport renderer are covered by their own tests.
