# Дальность Glory Kill / Chainsaw — локальная v24

В v25 экспериментальная карта убрана по просьбе пользователя: заливка,
контуры, штриховка и подписи не выводятся и не вычисляются при игре.
Подсветка частей тела с фильтрацией по дальности сохранена. Код карты
подключён только к офлайн-тестам для дальнейшего исследования; описание
ниже относится к экспериментальной v24, а не к текущему интерфейсу.

Карта использует общую логику для всех поддержанных врагов retail 1.1.
Она строится на высоте ног игрока и для текущего native-наведения;
при удержании цели используется последняя область наведения.

Белые контуры показывают смену набора доступных клипов. Цветная заливка
различает единственный вариант; розовая штриховка показывает несколько
клипов в полосе случайного выбора. Серый означает недостаточные данные.
Недоступные по дальности части тела скрываются и в автоматическом режиме,
и при ручном выборе клипа. Цвета частей из v23 сохранены.

Для GK учитываются отдельные native-ветви, их стартовые позиции, радиусы,
высота, угол, lunge и общий camera-to-target предел. Для QUICK_CHAINSAW
используется его собственный радиус и native-обход направленных GK-проверок.
Приоритет применяется перед расстоянием; затем сравниваются полные 3D
расстояния до стартовых позиций с прочитанным допуском. Повторяющиеся имена
клипов сохраняют все ветви, но сами по себе не образуют случайный выбор.
Взаимоисключающие условия наведения тоже не создают случайной области.

Это условная карта, привязанная к врагу. Для уникальной подготовленной
ветви используются текущие скорректированные native-позиции. Остальные
GK-позиции — исходные шаблоны, что явно указано в HUD. Неизвестные
приоритеты, позиции и условия не заменяются догадками: область остаётся
серой. Препятствия, состояние врага и поздние проверки игры могут запретить
исполнение. Альтернативы `LEASTUSED` внутри одного declaration не выдаются
за отдельные случайные позиционные варианты.

Границы дискретизированы адаптивно, до 1/256 ширины охваченной области
(около 5–8 см при радиусах 6,5–10 м). Заливка допускается только если
геометрические ограничения и класс выбора доказаны для всей ячейки.
Неопределённые пограничные ячейки остаются без заливки. Карта кэшируется;
изменение XY игрока обновляет текущий статус без перестроения геометрии.

Проверки входят в `SyncTargetTests`. Режим `--distance-only` запускает
только проверки дальности. Набор охватывает 25 семейств, 96 000 положений
по направлениям/высоте/дальности и обоим действиям, шесть записанных
исполнений Hell Knight, независимую проверку заливки по native-формуле,
приоритеты, одинаковые имена, разные условия наведения, скрытие
недоступных частей тела и обновление кэша. Полный прогон сохраняет
проверки цветов Carcass и остальных моделей из v23.

Матрицы из текущей игры доступны для части шаблонов. Для отсутствующих
шаблонов общий аудит использует явно контролируемые матрицы; это проверка
вычислений, а не утверждение о живой проверке каждого врага в игре.
