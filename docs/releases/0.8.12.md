# LAB Plus 0.8.12

## BATS and patch compatibility

- Adds audited BATS calculation support for DOOM Eternal 5.1 while retaining 1.0/1.1 checks. Equivalent executable code can be located through a bounded, unique signature search with helper/constant verification.
- BATS displays only **active** / **inactive**. Diagnostic verification remains separate: an unsupported build can display inactive without proving that no buff exists.
- Normal weapon bring-up rate now accounts for the active weapon mode, desired animation duration, normal clip length, Dexterity and neutral status effects. Includes weapon configuration and malformed metadata regression tests.
- Includes regression coverage for normal weapon configurations, mode selection, malformed metadata and false-positive controls. Chainsaw and Sentinel Hammer still need additional live validation.

## Application lifetime

- Closing LAB Plus disables its commands, collision/research overlays, HUD and lighting correction while the game stays open. Starting LAB Plus again restores eligible features.
- A second LAB Plus instance shows a warning and leaves the original instance running.

## Known compatibility limits

The base **6.66 Rev 3.2** profile is included, but this release does **not** add full support for its newer observations. Enemy HP requires compatible reflected health metadata; equipment/sticky timers and BATS remain subject to their separate audited-code checks. Active Fast DBlade, powerup, stagger and sync-animation scenarios on this patch still need validation. A base game profile alone does not imply support for every observation.

## Install

Extract the entire Windows x64 ZIP into one folder and run **LABPlus.exe**. Requires **.NET 10 Desktop Runtime x64** and **Microsoft Edge WebView2 Evergreen Runtime**. Restart the game completely after replacing native DLLs. Retains the existing selected-executable firewall requirement. The release includes a SHA-256 checksum file.

## Validation

Native BATS, weapon-configuration and application-lifetime checks; managed launcher checks; existing viewer/regression suites. Public fixtures use synthetic data; retail-code audit fixtures are kept local and excluded from source distribution. GitHub Actions builds and validates the release archive from the tagged source.
