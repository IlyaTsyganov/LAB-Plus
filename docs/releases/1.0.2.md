# LAB Plus 1.0.2

- Redesigned the Saves page: checkpoint controls and the Steam save-folder picker are now in the main window.
- Added custom categories, moving saves between categories, Up/Down ordering, and multi-selection deletion. Save, Load and Delete share the same button size and style.
- Archives can load into another existing slot of the same campaign. The Steam account and game patch must still match.
- Manual pause is no longer required for saving or loading. Save can also copy a completed checkpoint at the loading prompt, before entering the level; operations wait for active save writes to finish.
- Added `labplus_load_last_save` to load the last archive for the current account, patch and campaign. Deleted, unavailable or damaged last saves report an error instead of falling back to an older archive.
- DLC checkpoints stay visible and deletable on older patches, with loading disabled: TAG1 requires 3.0+, TAG2 requires 5.0+.
- Improved compatibility messages, renamed the main campaign label to Main, and kept the interface on the bundled asset fonts.

Loading still requires an entered destination slot. Compatible archives keep their normal appearance in the main menu, with an explanation of how to enable Load. Loading prompts respect the user's configured continue control.

Automated adapter checks cover all 22 supported patches. The new no-pause, pre-entry capture and console-command flows were also tested in-game on 1.1.
